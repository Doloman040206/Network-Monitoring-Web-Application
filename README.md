# Network Monitoring Web Application (Flask + Docker + Zabbix + Wireshark)

## 📌 Опис проєкту
Даний вебзастосунок реалізований на основі мови програмування Python та мікрофреймворку Flask і призначений для демонстрації моніторингу доступності вебсервісу, збору статистики HTTP-запитів та аналізу мережевого трафіку.

Застосунок побудований за клієнт-серверною архітектурою з використанням контейнеризації Docker та Docker Compose.

---

## 🎯 Функціональні можливості

### 🌐 Вебзастосунок Flask
- відображає головну сторінку вебзастосунку
- надає endpoint для перевірки стану сервісу `/health`
- надає API для отримання статистики `/api/stats`
- надає тестовий endpoint `/api/test-request`
- автоматично підраховує кількість HTTP-запитів
- вимірює середній час обробки запитів
- зберігає статистику запитів у базі даних SQLite

### 📊 Моніторинг Zabbix
- перевіряє доступність Flask-застосунку через HTTP agent
- надсилає GET-запити до endpoint `/health`
- перевіряє отримання HTTP-відповіді зі статусом `200`
- відображає останні отримані дані в інтерфейсі Zabbix
- дозволяє виявити припинення відповідей після зупинки Flask-контейнера

### 🐳 Контейнеризація Docker
- запускає Flask-застосунок в окремому контейнері
- запускає Zabbix Server та Zabbix Web
- використовує PostgreSQL для зберігання даних Zabbix
- забезпечує взаємодію контейнерів через спільну Docker-мережу
- використовує Docker volumes для збереження даних

### 🦈 Аналіз мережевого трафіку Wireshark
- перехоплює HTTP-запити до Flask-застосунку
- дозволяє аналізувати TCP-з’єднання
- використовується для дослідження локального трафіку через loopback-адаптер
- дає змогу перевірити передавання HTTP-запитів і відповідей

---

## 🧱 Структура бази даних

Проєкт використовує дві бази даних.

Основна статистика вебзастосунку зберігається в реляційній базі даних SQLite.

Система містить основну сутність:

- Request – інформація про HTTP-запит, його endpoint, тривалість обробки та час створення

Для системи моніторингу Zabbix використовується PostgreSQL, у якій зберігаються службові дані Zabbix, налаштування моніторингу та історія отриманих показників.

## 🛠 Використані технології

- Python 3.12 — мова програмування
- Flask — backend-фреймворк для створення вебзастосунку
- SQLite — реляційна база даних для зберігання статистики запитів
- SQL — робота з таблицею статистики
- Docker — контейнеризація застосунку та інфраструктурних компонентів
- Docker Compose — запуск і керування взаємопов’язаними контейнерами
- PostgreSQL — база даних для Zabbix
- Zabbix 7.0 — система моніторингу доступності вебзастосунку
- Wireshark — перехоплення та аналіз мережевого трафіку
- HTTP / JSON — обмін даними між клієнтом, Flask та системою моніторингу

---

## 🌐 Інтерфейс користувача

- HTML-сторінка генерується Flask-застосунком через шаблон `index.html`
- вебзастосунок доступний за адресою `http://localhost:5000`
- Zabbix Web доступний за адресою `http://localhost:8080`
- на головній сторінці відображаються основні показники роботи застосунку
- використовується:
  - відображення загальної кількості HTTP-запитів
  - відображення середнього часу відповіді
  - індикатор поточного стану застосунку
  - API endpoint для перевірки доступності
  - JSON-відповіді для взаємодії з іншими системами

## ▶️ Запуск проєкту

Для запуску всіх компонентів необхідно виконати команду:

```powershell
docker compose up -d --build
```

Після запуску доступні такі адреси:

- Flask Web Application: `http://localhost:5000`
- Flask Health Check: `http://localhost:5000/health`
- Flask API Statistics: `http://localhost:5000/api/stats`
- Zabbix Web Interface: `http://localhost:8080`

Для перевірки стану контейнерів можна використати команду:

```powershell
docker compose ps
```

Для зупинки контейнерів:

```powershell
docker compose stop
```

Для повторного запуску контейнерів:

```powershell
docker compose start
```
